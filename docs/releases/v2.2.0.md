# v2.2.0 — security fixes

A security update. Install it before the next game.

- **Fixed: files could be written, or folders deleted, from outside.** A team or game id could contain `../`, so a request could write a `.json` file anywhere on the computer. On Windows, it could also delete a whole folder. Ids are now checked.
- **Fixed: any web page could use OpenStatsEngine.** It allowed every website to call its API, so a page open in a browser on any computer on the network could change or delete things. Other sites can still *read* the XML and JSON (vMix and graphics pages keep working), but only OpenStatsEngine's own pages can change anything.
- **Open it by IP, `localhost`, the computer's name or a `.local` name.** Other names are refused, so a web page can't point its own domain at this computer. If you use a real DNS name, add it with `OSE_ALLOWED_HOSTS` (see the manual).

Your teams, rosters and games are not touched.
